# Seguridad y Gobernanza Azure — ZIP corregido

## Incluye
- `index.html`: dashboard principal.
- `styles.css`: tema Azure oscuro y diseño adaptable a escritorio, tablet y móvil.
- `app.js`: tarjetas interactivas para Integración, Certificación, QA y Prod.

## Cambios
- Environment muestra los cuatro entornos en orden.
- Cada tarjeta muestra controles, métricas y detalles específicos al pulsarla.
- DevSecOps está contenido dentro de su panel y el flujo se adapta a pantallas pequeñas.
- Incluye métricas, controles de seguridad y monitoreo ilustrativo.

## Ejecutar
Abre `index.html` en el navegador. No requiere dependencias ni proceso de compilación.

## Publicar en GitHub Pages
Sube los archivos a la raíz del repositorio y configura GitHub Pages desde Settings → Pages.
Las métricas de este dashboard son demostrativas y no se conectan a servicios reales.
